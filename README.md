# Temperature Neural Network Classifier

## Project Overview

This project demonstrates temperature classification into Low, Medium, and High categories using a small neural network trained with Python and TensorFlow/Keras.

## Categories

* Low: Below 20°C
* Medium: 20°C to 30°C
* High: Above 30°C

## Technologies

* Python
* TensorFlow/Keras
* ESP32
* Wokwi Simulator
* Arduino C++
* GitHub

## Project Workflow

1. Prepare a labeled temperature dataset.
2. Train a small neural network using Python.
3. Test predictions with sample temperature readings.
4. Integrate the trained model into the ESP32 application.
5. Test the application in Wokwi.

## Expected Result

The system classifies temperature readings into Low, Medium, or High categories.

## Note

The initial dataset is intended for demonstration and requires more representative data for reliable real-world performance.
